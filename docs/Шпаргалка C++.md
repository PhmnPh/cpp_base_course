## Типы (типичные размеры, 64-бит macOS)

| Тип | Байт | Про что |
|---|---|---|
| `bool` | 1 | `true` / `false` |
| `char` | 1 | символ / −128…127 |
| `short` | 2 | −32 768…32 767 |
| `int` | 4 | ±2·10⁹ |
| `long` / `long long` | 8 | ±9·10¹⁸ |
| `float` | 4 | ~7 знаков |
| `double` | 8 | ~15 знаков ← **по умолчанию** |

`sizeof(x)` — реальный размер здесь и сейчас.

## Ввод-вывод

```cpp
cin >> a >> b;
cout << "sum = " << a + b << "\n";

cout << fixed << setprecision(2) << x;    // 2 знака после точки
cout << setw(7) << setfill('$') << x;     // ширина 7, setw однократный
cout << hex << n;                          // шестнадцатеричный

printf("%d %.2f %s\n", n, x, "text");
scanf("%d%lf", &n, &x);                    // %lf для double!
```

## Ловушки

| Пишешь | Получаешь | Как надо |
|---|---|---|
| `1 / 2` | `0` | `1.0 / 2` |
| `int x = 2.75` | `2`, молча | `int x{2.75}` → ошибка |
| `-7 % 2` | `-1` (не как в Python) | — |
| `012` | `10` (восьмеричное) | `12` |
| `a == b` для `double` | случайный результат | `fabs(a-b) < 1e-9` |
| `x % 4` для `float` | ошибка компиляции | `(int)x % 4` |
| целочисленное `/ 0` | падение | проверять делитель |
| `if (1 < x < 10)` | всегда `true` | `1 < x && x < 10` |
| `if (x = 5)` | присваивание | `x == 5` |
| `INT_MAX + 1` | `-2147483648`, тихо | `long long` |
| `int i = -1; i < 1u` | `false` (!) | не мешать `int` и `unsigned` |
| `cout << a & 1` | не компилируется | `cout << (a & 1)` |
| `cin >> n` при вводе букв | `n == 0`, ввод сломан | `if (!(cin >> n)) { cin.clear(); ... }` |

## Операции по приоритету (сверху вниз)

```

++ -- (префикс)  ! -  +  (унарные)  (тип)  sizeof
*  /  %
+  -
<< >>
<  <=  >  >=
==  !=
&&
||
?:                          ← правоассоциативна
=  +=  -=  *=  /=  %=       ← правоассоциативны
```

Сомневаешься — ставь скобки.

## Сборка

```bash
clang++ -std=c++17 -Wall -Wextra -g file.cpp -o file && ./file
```

`clang` (не `clang++`) не линкует libc++ → «Undefined symbols for `std::`».
