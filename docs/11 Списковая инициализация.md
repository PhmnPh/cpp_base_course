# 11. Списковая инициализация

← [C++ — оглавление](<./C++ — оглавление.md>)

C++11: унифицированный способ задать значение чему угодно — переменной, массиву, объекту. Инициализатор в **фигурных** скобках, `=` можно опустить.

```cpp
int n = { 10 };   // n == 10
char ch{ 65 };    // ch == 'A'
int m{};          // m == 0 — гарантированная инициализация нулём
```

## Главное преимущество: защита от сужения

Обычная инициализация молча теряет данные:

```cpp
int x = 2.75;
cout << x;        // 2, компилятор молчит
```

Списковая — ошибка компиляции:

```cpp
int x = { 2.75 };     // ошибка: narrowing conversion
char sim = { 300 };   // ошибка: 300 вне диапазона char
short i{ 70000 };     // ошибка: максимум short — 32 767
```

> [!tip] Правило
> Хочешь ловить потерю данных на компиляции, а не отлаживать её потом — инициализируй фигурными скобками.

> [!note] Ещё пара плюсов
> - `int m{};` всегда даёт 0 — не остаётся мусора → см. [03 Переменные и константы](<./03 Переменные и константы.md>)
> - `Widget w{};` не путается с объявлением функции (проблема «most vexing parse»), в отличие от `Widget w();`
> - тот же синтаксис работает для контейнеров: `vector<int> v{1, 2, 3};`

> [!warning] Одно исключение
> Для `std::vector` фигурные скобки предпочитают конструктор со списком:
> ```cpp
> vector<int> a(3, 0);   // три нуля
> vector<int> b{3, 0};   // два элемента: 3 и 0
> ```
