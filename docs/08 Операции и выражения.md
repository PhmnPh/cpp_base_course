# 08. Операции и выражения

← [C++ — оглавление](<./C++ — оглавление.md>)

## Присваивание

`=` — вычислить выражение справа, положить результат в переменную слева. Старое значение затирается.

```cpp
a = a + 1;   // в математике неверно, в программировании нормально
```

### Обмен значений двух переменных

Нужна третья переменная — как третий стакан, чтобы перелить воду и кофе:

```cpp
tmp = a;   // сохранили копию a
a = b;     // теперь можно портить a
b = tmp;   // вернули сохранённое
```

> [!tip] В C++ это делается одной строкой
> ```cpp
> #include <utility>
> swap(a, b);
> ```

## Выражения

Состоят из операндов (переменных, констант, литералов), знаков операций и скобок:

```cpp
(a + 0.12) / 6
x && y || !z
a = b = c
```

По числу операндов:

| Вид | Операндов | Пример |
|---|---|---|
| унарная | 1 | `a++`, `-b` |
| бинарная | 2 | `a + b`, `x / y` |
| тернарная | 3 | `a > b ? a : b` |

## Приоритет и ассоциативность

**Приоритет** — что вычисляется раньше: в `a + b * 3` сначала `*`. Меняется круглыми скобками.

**Ассоциативность** — как расставляются скобки при равном приоритете.

- большинство операций **левоассоциативны**: `a + b + c` ≡ `(a + b) + c`
- исключения (**правоассоциативны**): унарные, `?:`, все присваивания

```cpp
a = b = c;   // ≡ a = (b = c)
```

Разбор `a < b ? c : d > 0 ? c : a`:
`<` и `>` приоритетнее `?:`, а `?:` правоассоциативна →
`a < b ? c : (d > 0 ? c : a)`

> [!tip] Не заучивай таблицу приоритетов
> Ставь скобки там, где сомневаешься. Читателю кода тоже легче.

## Арифметические операции

| | |
|---|---|
| `-x` | унарный минус |
| `+x` | унарный плюс (ничего не делает) |
| `x + y` `x - y` `x * y` | сложение, вычитание, умножение |
| `x / y` | деление |
| `x % y` | остаток от деления (**только целые**) |

### Деление зависит от типа операндов

```cpp
1 / 2        // 0    — оба целые, дробная часть отброшена
1.0 / 2      // 0.5  — один вещественный
(double)a / 2
```

> [!danger] Самая частая ошибка новичка
> `int a = 1, b = 2; double x = a / b;` даст `0`, а не `0.5`. Приводи тип **до** деления.

### Остаток

Если `k = a / b` и `c = a % b`, то `a == b * k + c`.

```
7 / 2 = 3,   7 % 2 = 1     (2*3+1 = 7)
19 / 5 = 3,  19 % 5 = 4
34 / 6 = 5,  34 % 6 = 4
```

Остаток всегда меньше делителя по модулю.

**Отрицательные операнды:** берутся модули, вычисляется остаток, приписывается **знак делимого**.

```cpp
cout <<  7 %  2;   //  1
cout << -7 %  2;   // -1
cout <<  7 % -2;   //  1
cout << -7 % -2;   // -1
```

> [!note] В Python иначе
> `-7 % 2` в Python даёт `1` (знак делителя), в C++ — `-1`. См. [Из Python в C++](<./Из Python в C++.md>).

### Деление на ноль

| | Результат |
|---|---|
| вещественное | `inf` (не ошибка), `0.0/0.0` → `nan` |
| целое `/` и `%` | **ошибка выполнения**, программа падает |

## Инкремент и декремент

```cpp
a++;   // ≡ a = a + 1
b--;   // ≡ b = b - 1
```

| Форма | Порядок |
|---|---|
| **префиксная** `++a` | сначала увеличить, потом использовать |
| **постфиксная** `a++` | сначала использовать, потом увеличить |

```cpp
int a = 3;  cout << ++a;   // 4, a == 4
int a = 3;  cout << a++;   // 3, a == 4
```

> [!warning] Не пиши `i = i++ + ++i`
> Несколько изменений одной переменной в одном выражении — undefined behavior. Компиляторы дают разный результат.

## Сокращённые присваивания

```cpp
a += 10;   // a = a + 10
a -= 10;
a *= 10;
a /= 10;
a %= 10;
```

## Тернарная операция

```
операнд_1 ? операнд_2 : операнд_3
```

Операнд 1 приводится к `bool`. Если `true` — результат операнда 2, иначе — операнда 3.

```cpp
c = (a > b) ? a : b;         // максимум из двух
i = (i < n) ? i + 1 : 1;     // циклический счётчик
```
