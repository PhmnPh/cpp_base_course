# 04. Базовые типы данных

← [C++ — оглавление](<./C++ — оглавление.md>)

## Целочисленные

| Тип | Байт | Диапазон |
|---|---|---|
| `char` | 1 | −128 … 127 |
| `unsigned char` | 1 | 0 … 255 |
| `short` | 2 | −32 768 … 32 767 |
| `unsigned short` | 2 | 0 … 65 535 |
| `int` | 4 | −2 147 483 648 … 2 147 483 647 |
| `unsigned int` | 4 | 0 … 4 294 967 295 |
| `long` | 4 | как `int` |
| `unsigned long` | 4 | 0 … 4 294 967 295 |
| `long long` | 8 | ±9,22·10¹⁸ |
| `unsigned long long` | 8 | 0 … 2⁶⁴−1 |

Расчёт диапазона → [02 Данные в памяти компьютера](<./02 Данные в памяти компьютера.md>): без знака `0 … 2ⁿ−1`, со знаком `−2ⁿ⁻¹ … 2ⁿ⁻¹−1`.

Модификаторы: `unsigned` — без знака, `signed` — со знаком (по умолчанию).

**Историческая странность:** `long` должен был быть вдвое длиннее `int`, но на практике совпал с ним. Поэтому в C++11 добавили `long long`.

> [!warning] Размеры не гарантированы стандартом
> Таблица верна для Windows/MSVC и типичных 32-битных сборок. **На macOS/Linux 64-бит `long` занимает 8 байт**, а не 4. Стандарт гарантирует только минимумы и `char ≤ short ≤ int ≤ long ≤ long long`.
> Если нужен точный размер — `<cstdint>`: `int32_t`, `uint64_t`, `int8_t`.

### Переполнение — чего курс не сказал

Диапазон конечен, и выход за него **не** вызывает ошибку.

```cpp
int big = 2147483647;
big = big + 1;
cout << big;        // -2147483648
```

| | Что происходит при выходе за диапазон |
|---|---|
| **знаковые** (`int`, `long`) | **UB** — компилятор вправе оптимизировать так, будто переполнения не бывает |
| **беззнаковые** (`unsigned`) | определено стандартом: заворачивание по модулю 2ⁿ |

```cpp
unsigned int u = 0;
u = u - 1;          // 4294967295 — легально, но обычно не то, что задумано
```

> [!danger] Смешивать `int` и `unsigned` в сравнении опасно
> ```cpp
> int i = -1;
> unsigned u = 1;
> if (i < u) cout << "меньше";   // НЕ выведется!
> ```
> Перед сравнением `i` приводится к `unsigned` (см. иерархию в [10 Преобразование типов](<./10 Преобразование типов.md>)) и становится 4294967295. Отсюда правило: **не используй `unsigned` просто потому, что «число не бывает отрицательным»** — бери `int`.

### Узнать границы типа

```cpp
#include <limits>
cout << numeric_limits<int>::max();      // 2147483647
cout << numeric_limits<int>::min();
cout << numeric_limits<double>::epsilon();
```

Си-шный вариант: `#include <climits>` → `INT_MAX`, `CHAR_MIN`, `LLONG_MAX`.

## Символьные

`char` — 1 байт, код символа. Одновременно и целочисленный тип: участвует в арифметике.

```cpp
char c = 'A';
cout << c << " " << (int)c;   // A 65
cout << char('a' + 1);        // b
```

Кодовая таблица: коды 0–31 — служебные (непечатаемые), 32–127 — ASCII, 128–255 — национальные алфавиты, зависят от кодировки. `setlocale()` переключает программу на другую кодовую таблицу.

Полезные факты про ASCII, которые дальше пригодятся в задачах:

| Диапазон | Коды | Приёмы |
|---|---|---|
| `'0'`–`'9'` | 48–57 | цифра из символа: `c - '0'` |
| `'A'`–`'Z'` | 65–90 | |
| `'a'`–`'z'` | 97–122 | регистр: `c + 32` вниз, `c - 32` вверх (ровно 32 = 1 бит) |

```cpp
char c = '7';
int digit = c - '0';                    // 7
bool isDigit = (c >= '0' && c <= '9');  // или isdigit(c) из <cctype>
```

> [!warning] `char` — знаковый или беззнаковый?
> Стандарт не определяет. На x86 обычно знаковый (−128…127), на ARM — часто беззнаковый. Поэтому для символов с кодом >127 (кириллица в однобайтной кодировке) поведение платформозависимо. Если важно — пиши явно `signed char` / `unsigned char`.

**Unicode** (1991): символ 2 или 4 байта, все алфавиты сразу — решает проблему «кракозябр». В C++11 для этого есть `char16_t` и `char32_t` (в C++20 ещё `char8_t`). В курсе используем однобайтный `char`.

## Вещественные

| Тип | Байт | Диапазон (по модулю) | Знаков точности |
|---|---|---|---|
| `float` | 4 | 3.4e−38 … 3.4e+38 | ~7 |
| `double` | 8 | 1.7e−308 … 1.7e+308 | ~15 |
| `long double` | 10* | 3.4e−4932 … 3.4e+4932 | ~18 |

Устройство (IEEE 754):

| | Знак | Порядок | Мантисса |
|---|---|---|---|
| `float` | 1 бит | 8 бит | 23 бита |
| `double` | 1 бит | 11 бит | 52 бита |

Старшая цифра мантиссы всегда 1 и не хранится («неявный бит»).

Числа, близкие к нулю, неразличимы: для `float` всё в диапазоне ±3.4e−38 — это 0.

> [!note] `long double` = 10 байт?
> Это x87-формат (80 бит), выровненный до 12/16 байт. **На Apple Silicon (ARM) `long double` — это просто `double`, 8 байт.** Проверяй `sizeof`, не память.

> [!tip] Правило по умолчанию
> Для вещественных бери `double`. Литералы с точкой и так `double`, математические функции тоже — `float` даст лишние преобразования и потерю точности без выигрыша.

## Логический

`bool` — `true` / `false`, занимает 1 байт (адресовать меньше нельзя).

## `sizeof`

Даёт размер типа или переменной в байтах для **этой** реализации. Аргумент — тип или имя переменной.

```cpp
#include <iostream>
using namespace std;

int main() {
    int i;
    cout << sizeof(i) << "\n";        // 4
    cout << sizeof(long) << "\n";     // 4 (MSVC) / 8 (macOS, Linux)
    cout << sizeof(double) << "\n";   // 8
    return 0;
}
```
