# 06. Литералы

← [C++ — оглавление](<./C++ — оглавление.md>)

Литерал — константа без имени. Тип компилятор определяет **по внешнему виду**.

## Целые

По умолчанию `int`. Суффиксы меняют тип:

| Суффикс | Тип |
|---|---|
| `L` / `l` | `long` |
| `U` / `u` | `unsigned` |
| `LL` | `long long` |
| комбинация | `22UL`, `5Lu` |

Системы счисления — префиксом:

| Префикс | Система | Пример |
|---|---|---|
| — | десятичная | `26` |
| `0` | восьмеричная | `057` = 47 |
| `0x` / `0X` | шестнадцатеричная | `0x1A` = 26 |
| `0b` / `0B` | двоичная (C++14) | `0b1010` = 10 |

> [!tip] Разделитель разрядов (C++14)
> `1'000'000`, `0b1010'0110` — апостроф игнорируется компилятором, читается легче.

> [!warning] Ведущий ноль
> `012` — это **не** 12, а 10 (восьмеричное). Классическая ловушка при записи дат и времени.

## Вещественные

По умолчанию `double`. С фиксированной точкой (`3.14`) или с плавающей (`2.148E2`).

| Суффикс | Тип |
|---|---|
| `F` / `f` | `float` |
| `L` / `l` | `long double` |

`2E+6L` → `long double`, `3.14f` → `float`.

## Символьный

Один символ в апострофах: `'R'`, `'*'`.

Escape-последовательности: `'\n'` перевод строки, `'\t'` табуляция, `'\\'` бэкслеш, `'\''` апостроф, `'\0'` нулевой символ.

## Булев

Только `true` и `false`.

## Строковый

Последовательность в двойных кавычках: `"Visual"`. Отдельного строкового *типа* в C нет — это массив `char` с завершающим `'\0'`. В C++ есть `std::string` (`#include <string>`).

## Пример

```cpp
#include <iostream>
using namespace std;

int main() {
    setlocale(LC_ALL, "rus");
    long i = 28l;                                   // long
    i = 5;                                          // int
    cout << "Восьмеричное: "     << 057   << "\n";  // 47
    cout << "Шестнадцатеричное: " << 0x1A << "\n";  // 26
    double x;
    x = 3.14 * i;                                   // double
    x = 3.14f * i;                                  // float * long -> double
    cout << "Вещественное: " << 2.148E2 << "\n";    // 214.8
    bool flag = true;
    char ch = '%';
    return 0;
}
```

> [!note] Вывод всегда десятичный
> Потоковый вывод по умолчанию печатает в десятичной системе и в формате с фиксированной точкой, независимо от того, как литерал записан в коде. Менять формат — манипуляторами → [07 Потоковый ввод-вывод и манипуляторы](<./07 Потоковый ввод-вывод и манипуляторы.md>).
