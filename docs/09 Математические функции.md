# 09. Математические функции

← [C++ — оглавление](<./C++ — оглавление.md>)

```cpp
#include <cmath>    // предпочтительно в C++
// или <math.h>, <stdlib.h>
```

В Visual Studio подключаются по умолчанию, в clang/gcc — нужно явно.

Аргументы и результаты по умолчанию `double`. **Если нет причин экономить память — используй `double`.**

## Основные

| Функция | Что делает |
|---|---|
| `abs(x)` / `fabs(x)` | модуль (целый / вещественный) |
| `sqrt(x)` | квадратный корень |
| `pow(x, y)` | x в степени y |
| `exp(x)` | eˣ |
| `log(x)` / `log10(x)` | натуральный / десятичный логарифм |
| `sin` `cos` `tan` | тригонометрия (аргумент в **радианах**) |
| `asin` `acos` `atan` | обратные тригонометрические |
| `atan2(y, x)` | арктангенс y/x с учётом четверти |

## Округление

Результат — **вещественное** число (с нулевой дробной частью).

| Функция | Действие | `2.7` | `-2.7` |
|---|---|---|---|
| `floor(x)` | вниз | 2 | −3 |
| `ceil(x)` | вверх | 3 | −2 |
| `round(x)` | к ближайшему | 3 | −3 |
| `trunc(x)` | отбросить дробь | 2 | −2 |

Приведение `(int)x` работает как `trunc`.

## Число π

```cpp
double pi = atan(1) * 4;
```

или через константу:

```cpp
#define _USE_MATH_DEFINES
#include <cmath>
// M_PI
```

> [!tip] C++20
> `#include <numbers>` → `std::numbers::pi`. Без макросов и платформенных плясок.

## Пример

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    double x, y;
    setlocale(LC_ALL, "rus");
    cout << "Введите аргумент: ";
    cin >> x;
    y = sqrt(2.) / 2 * sin(x / 2);
    cout << "Результат функции: " << y << "\n";
    return 0;
}
```

> [!note] Зачем точка в `sqrt(2.)`
> `2.` — литерал `double`. Без точки был бы `int` и произошло бы неявное расширение — работает, но привычка писать точку страхует от целочисленного деления рядом.
