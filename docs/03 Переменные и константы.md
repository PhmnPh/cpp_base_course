# 03. Переменные и константы

← [C++ — оглавление](<./C++ — оглавление.md>)

## Переменная

Именованная область памяти, значение которой можно менять. Имеет **имя**, **тип** и **значение**.

> Аналогия: ящик с этикеткой. Имя — этикетка, тип — размер ящика, значение — содержимое.

Описывается **до** первого использования, но в любом месте программы (в отличие от Паскаля).

```cpp
int a = 70;   // a — имя, int — тип, 70 — начальное значение
```

> [!danger] Неинициализированная переменная
> Если начальное значение не задано, в памяти лежит мусор от прежних данных. Чтение такой переменной — undefined behavior. **Всегда инициализируй при объявлении.**

## Изменение значения

```cpp
cin >> a;   // ввод с клавиатуры, старое значение затирается
a = 25;     // присваивание
```

`cin` — стандартный поток ввода (console in), `>>` — оператор извлечения. → [07 Потоковый ввод-вывод и манипуляторы](<./07 Потоковый ввод-вывод и манипуляторы.md>)

## Константа

Область памяти под постоянные данные. Ключевое слово `const`, **обязательна** инициализация. Имена — прописными.

```cpp
const double PI = 3.1415;
PI = 3;   // ошибка компиляции
```

> [!tip] `constexpr` вместо `const`
> Если значение известно на этапе компиляции — бери `constexpr` (C++11): компилятор гарантирует вычисление на компиляции и разрешает использовать значение там, где нужна константа времени компиляции (размеры массивов и т.п.).
> ```cpp
> constexpr double PI = 3.1415;
> ```

## Типы данных

Тип определяет, сколько памяти выделено и как её интерпретировать → отсюда диапазон значений и допустимые операции.

- **базовые** — целые, вещественные, символьные, логические → [04 Базовые типы данных](<./04 Базовые типы данных.md>)
- **составные** — массивы, структуры, объединения, перечисления, ссылки, указатели
