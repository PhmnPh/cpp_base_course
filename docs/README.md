# Конспекты курса C++

Здесь хранятся конспекты глав курса, оглавление, шпаргалка и дополнительные заметки. Практические задания и примеры кода находятся в остальных каталогах репозитория.

Начни с [оглавления курса](<./C++ — оглавление.md>). Для повторения есть [шпаргалка](<./Шпаргалка C++.md>).

Одна глава или тема — один Markdown-файл. Названия и нумерация сохранены при переносе из Obsidian. Заметки редактируются здесь, чтобы не поддерживать две расходящиеся копии.
