# 12. Ввод-вывод в стиле C (printf/scanf)

← [C++ — оглавление](<./C++ — оглавление.md>)

```cpp
#include <cstdio>   // или <stdio.h>
```

Классический ANSI C. На Stepik в части задач требуется именно он.

## `printf`

```cpp
printf("управляющая строка", список аргументов);
```

Управляющая строка обязательна, аргументов может не быть вовсе. Строка содержит:
1. обычные символы — выводятся как есть
2. escape-последовательности: `\n`, `\t`
3. **спецификации преобразования** — «держатели места» (place holders), начинаются с `%`

Аргументы подставляются на места спецификаций **по порядку**.

### Спецификации

| Спец. | Что выводит |
|---|---|
| `%d` | десятичное целое |
| `%o` | восьмеричное целое |
| `%x` | шестнадцатеричное целое |
| `%u` | десятичное без знака |
| `%f` | вещественное с точкой (`82.312`) |
| `%e` | вещественное в экспоненциальном виде (`8.2312e+01`) |
| `%g` | короче из `%f` / `%e` |
| `%c` | символ |
| `%s` | строка |
| `%p` | указатель (адрес в hex) |
| `%%` | сам знак процента |

### Формат целых

Между `%` и символом формата:
- `-` — выравнивание **влево** (по умолчанию вправо)
- число — **минимальная** ширина поля; не хватает — добивается пробелами, не влезает — выводится целиком

```cpp
int k = 30;
printf("|%4d|\n|%-4d|\n", k, k);
//   |  30|
//   |30  |

int l = 55, j = 22556;
printf("|%4d|\n|%4d|\n", l, j);
//   |  55|
//   |22556|      ширина проигнорирована
```

### Формат вещественных

Дополнительно: `.` и число после неё — количество знаков после точки (больше → округление, меньше → нули). Ширина считается **для всего числа**, включая знак и точку.

```cpp
double x = -56.489;
printf("x=%9.2f\n", x);    // x=   -56.49
printf("x=%.6f\n", x);     // x=-56.489000
printf("x=%10.6f\n", x);   // x=-56.489000
printf("Результат 100%%\n");
```

`printf` возвращает количество выведенных символов.

> [!danger] Несоответствие спецификации и типа
> `printf("%d", 3.14)` — undefined behavior, компилятор проверяет это только с `-Wformat` (включён по умолчанию в clang). Тип аргумента должен точно соответствовать спецификации.

## `scanf`

```cpp
scanf("управляющая строка", список указателей на переменные);
```

Аргументы — **указатели**, поэтому перед именем переменной ставится `&` (взятие адреса).

```cpp
float y;
int k;
printf("Введите y и k через пробел: ");
scanf("%f%d", &y, &k);
```

### Спецификации ввода

| Спец. | Тип |
|---|---|
| `%d` | `int` |
| `%o` `%x` `%u` | восьмеричное / шестнадцатеричное / беззнаковое |
| `%lld` | `long long` |
| `%f` | **`float`** |
| `%lf` | **`double`** |
| `%c` | символ |
| `%s` | строка |
| `%p` | указатель |

> [!danger] `%f` vs `%lf` — разница только при вводе
> При **вводе** `%f` — это `float`, `%lf` — `double`. Перепутать = порча памяти.
> При **выводе** оба работают одинаково (`float` расширяется до `double` автоматически).

### Правила

- элементы разделяются пробелами, ввод завершается Enter
- дробная часть — через точку
- символы табуляции и `\n` в управляющей строке игнорируются
- обычные символы в строке должны совпасть с входным потоком — **лучше не включать в неё ничего, кроме спецификаций**
- `*` между `%` и форматом — прочитать и **пропустить** (не записывать): `scanf("%*d%d", &x)`
- возвращает число успешно введённых элементов, `EOF` — при преждевременном конце файла

> [!note] `scanf_s` в Visual Studio
> MSVC 2013+ может требовать `scanf_s` — версию с дополнительным параметром «размер буфера», который защищает от выхода за пределы памяти при вводе строк. Для чисел размер не указывается, и синтаксис совпадает со `scanf`. Это **не** стандарт C++, на clang/macOS её нет. Отключить требование: `#define _CRT_SECURE_NO_WARNINGS` до `#include`.

> [!warning] Ввод символов и строк через scanf
> Связан с проблемами (остаток `\n` в буфере). Пока использовать только для чисел — разберём на теме строк.

## Что выбрать

| | `cout`/`cin` | `printf`/`scanf` |
|---|---|---|
| проверка типов | на компиляции | нет |
| форматирование | многословно | компактно |
| скорость | медленнее (можно ускорить) | быстрее |

Правило: в C++ по умолчанию → [07 Потоковый ввод-вывод и манипуляторы](<./07 Потоковый ввод-вывод и манипуляторы.md>). `printf` — когда нужно компактное форматирование или этого требует задача.
