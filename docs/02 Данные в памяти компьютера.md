# 02. Данные в памяти компьютера

← [C++ — оглавление](<./C++ — оглавление.md>)

## Бит и байт

- **бит** — один двоичный разряд (0/1), собственного адреса не имеет
- **байт** — 8 бит, минимальная **адресуемая** единица памяти

## Сколько значений влезает в n бит

Комбинаций: $2^n$. Максимальное беззнаковое число: $2^n - 1$.

| Бит | Комбинаций |
|---|---|
| 2 | 4 (`00 01 10 11`) |
| 3 | 8 |
| 8 | 256 → числа `0…255` |

## Числа со знаком

Старший бит отводится под знак: `0` — неотрицательное, `1` — отрицательное. На значение остаётся `n-1` бит.

Диапазон: от $-2^{n-1}$ до $2^{n-1}-1$. Для байта: `-128…127`.

> [!info] Почему минус на единицу больше
> Отрицательные хранятся в **дополнительном коде** (two's complement), а не «знак + модуль». Поэтому нет двух нулей (`+0`/`-0`) и появляется лишнее отрицательное значение. Практическое следствие: `-INT_MIN` переполняется — это UB.

### Дополнительный код за 30 секунд

Урок говорит «старший бит = знак», и это верно как описание, но не как способ получить число. Реально «−5» в байте получают так:

```
 5      =  0000 0101
инверт. →  1111 1010      (~5)
   +1   →  1111 1011      = −5
```

Проверка: `5 + (−5)` = `0000 0101 + 1111 1011` = `1 0000 0000`, девятый бит выпадает за пределы байта → `0`. ✔

Зачем так: процессору не нужна отдельная схема вычитания — `a − b` это `a + (−b)` обычным сложением.

Отсюда же «заворачивание» (wraparound): `127 + 1` = `0111 1111 + 1` = `1000 0000` = `−128`.

## Шестнадцатеричная система — зачем

Одна hex-цифра = ровно 4 бита, значит байт = ровно две цифры. Поэтому дампы памяти, коды цветов и адреса пишут в hex: короче двоичного и переводится в него в уме.

| Hex | Bin | Dec |
|---|---|---|
| `0` | 0000 | 0 |
| `8` | 1000 | 8 |
| `A` | 1010 | 10 |
| `F` | 1111 | 15 |

`0xFF` = `1111 1111` = 255 — максимум байта. `0x1A` = `0001 1010` = 26.

## Вещественные числа

Перед записью число **нормализуется**: `0,058` → `0,58 · 10⁻¹`

- `0,58` — **мантисса** (первая цифра после запятой ≠ 0)
- `-1` — **порядок**

Ячейка делится на часть под мантиссу (со знаком) и часть под порядок (со знаком). Мантисса даёт **точность**, порядок — **диапазон**.

Научная форма вывода: `0.58E-1`.

> [!warning] Следствие для практики
> `0.1 + 0.2 != 0.3`. Вещественные числа нельзя сравнивать на `==`, сравнивай модуль разности с эпсилоном:
> ```cpp
> if (fabs(a - b) < 1e-9) { /* равны */ }
> ```

## Адресация

Процессор обращается к байту целиком, зная его **адрес** в регистре.

| Разрядность ОС | Регистр адреса | Максимум памяти |
|---|---|---|
| 32 бита | 32 бита | $2^{32}$ = 4 294 967 296 байт ≈ **4 ГБ** |
| 64 бита | 64 бита | $2^{64}$ байт ≈ **16 эксабайт** |

Поэтому 32-битная ОС не увидит планки памяти сверх ~4 ГБ.
