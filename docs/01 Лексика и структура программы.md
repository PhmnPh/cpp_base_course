# 01. Лексика и структура программы

← [C++ — оглавление](<./C++ — оглавление.md>)

## Аналогия с естественным языком

| Естественный язык | Язык программирования |
|---|---|
| символы | символы алфавита |
| слова | **лексемы** |
| словосочетания | **выражения** |
| предложения | **операторы** |

## Алфавит (базовый набор символов)

- латинские буквы `A–Z`, `a–z` и знак подчёркивания `_`
- цифры `0–9`
- спецсимволы: `, . ; : ? ! ' " | / \ ~ ^ ( ) { } [ ] < > # % & - = + *`
- пробельные: пробел, табуляция, перевод строки

> [!warning] Кириллица не входит в базовый набор
> Имена в программе — только латиницей. Русские буквы допустимы **только внутри строковых литералов и комментариев** («набор символов реализации»).

## Лексемы

Минимальная единица, которую компилятор обрабатывает как единое целое. `128` — лексема, `12` внутри неё — нет.

Виды:
1. **идентификаторы** (имена)
2. **ключевые слова**
3. **знаки операций**
4. **разделители**
5. **литералы** (константы) → [06 Литералы](<./06 Литералы.md>)

### Идентификаторы

- буквы, цифры, `_`
- первый символ — буква (с `_` обычно начинаются служебные имена)
- регистр важен: `Sum` ≠ `sum`
- не совпадает с ключевым словом
- длина по стандарту не ограничена

Хорошие имена: `ageOfStudents`, `sumOfPositive`, `backColor`.
Избегай символов-двойников: `1` / `l` / `I`, `0` / `O`.

### Ключевые слова

Зарезервированы, использовать под свои имена нельзя. C++11-набор:

```
alignas alignof and and_eq asm auto bitand bitor bool break case catch
char char16_t char32_t class compl const constexpr const_cast continue
decltype default delete do double dynamic_cast else enum explicit export
extern false float for friend goto if inline int long mutable namespace
new noexcept not not_eq nullptr operator or or_eq private protected public
register reinterpret_cast return short signed sizeof static static_assert
static_cast struct switch template this thread_local throw true try typedef
typeid typename union unsigned using virtual void volatile wchar_t while
xor xor_eq
```

> [!note] Из более новых стандартов
> C++20 добавил `concept`, `requires`, `co_await`, `co_yield`, `co_return`, `consteval`, `constinit`, `char8_t`. В курсе не понадобятся, но пусть будут на виду.

### Знаки операций

Один или несколько символов, задающих действие. Пробелы внутри знака недопустимы: `&&`, а не `& &`. Бывают буквенными: `sizeof`, `new`.

### Разделители

Символы, разграничивающие лексемы: `; , ( ) { } [ ]` и пробельные. Пробел между лексемами не нужен, если они и так различимы: `a+b` ≡ `a + b`, но `int a` без пробела не запишешь.

## Выражения и операторы

**Выражение** задаёт правило вычисления значения: `a + b` — операнды `a`, `b` и знак операции `+`.

**Оператор** — законченное действие:

| | Пример |
|---|---|
| исполняемый | `a = b + 1;` |
| неисполняемый (описания) | `int a;` |
| составной (блок) | `{ ... }` |

Все операторы, кроме составного, завершаются `;`.

## Анатомия минимальной программы

Урок разбирает лексемы, но не говорит, из чего состоит сама программа. Разберём построчно:

```cpp
#include <iostream>     // 1. директива препроцессора
using namespace std;    // 2. подключение пространства имён

int main() {            // 3. точка входа
    cout << "Hi\n";     // 4. оператор
    return 0;           // 5. код завершения
}
```

**1. `#include`** — директива **препроцессора** (всё, что начинается с `#`). Препроцессор работает до компилятора и буквально подставляет содержимое файла `<iostream>` в это место. Никакого «импорта модуля», как в Python, — это текстовая вставка.

- `<имя>` — искать в системных каталогах (стандартная библиотека)
- `"имя"` — сначала рядом с текущим файлом (свои заголовки)

**2. `using namespace std;`** — всё из стандартной библиотеки живёт в пространстве имён `std`. Без этой строки писать `std::cout`, `std::cin`, `std::endl`.

> [!warning] `using namespace std` — только в учебном коде
> В заголовочных файлах и больших проектах так не делают: имена стандартной библиотеки вываливаются в глобальную область и конфликтуют с твоими (`count`, `distance`, `swap`, `data`). В настоящем коде пишут `std::` явно или точечно: `using std::cout;`

**3. `int main()`** — функция, с которой начинается выполнение. Ровно одна на программу. `int` — тип возвращаемого значения.

**4. Тело** — операторы в фигурных скобках, выполняются сверху вниз.

**5. `return 0;`** — код завершения для операционной системы: `0` — успех, любое другое число — ошибка. В `main` (и только в ней) `return 0` можно опустить — компилятор подставит сам.

> [!note] `system("pause")` из примеров курса
> Это костыль Visual Studio, чтобы консольное окно не закрылось мгновенно. На macOS/Linux он **не работает** и является лишним вызовом оболочки. В своих решениях его просто не пишем.

## Комментарии

```cpp
// однострочный — до конца строки
/* многострочный,
   вложенность не поддерживается */
```

Комментарии удаляет препроцессор, до компилятора они не доходят. Внутри них можно писать что угодно, в том числе по-русски.
