# 05. Область действия и видимости

← [C++ — оглавление](<./C++ — оглавление.md>)

Место описания переменной задаёт **область действия** её имени.

| | Где объявлена | Область действия |
|---|---|---|
| **локальная** | внутри блока `{ }` | от точки описания до конца блока, включая вложенные |
| **глобальная** | вне любого блока | от точки описания до конца модуля |

> [!tip] Совет
> Глобальные переменные — как можно реже. Чем уже область действия, тем проще искать ошибки.

## Видимость ≠ действие

**Область видимости** — часть текста, где имя можно явно использовать. Обычно совпадает с областью действия. Расходятся, когда во вложенном блоке объявлена переменная с тем же именем — внешняя **затеняется** (shadowing).

```cpp
#include <iostream>
using namespace std;

char simv = 'Y';            // глобальная

int main() {
    int k = 0;              // локальная
    {
        cout << "k= " << k << "\n";       // 0
        int k = 3;                        // затеняет внешнюю k
        cout << "k= " << k << "\n";       // 3
        cout << "simv= " << simv << "\n"; // Y — глобальная видна
    }
    cout << "k= " << k << "\n";           // 0 — снова доступна
    return 0;
}
```

Внутренняя `k` уничтожается при выходе из блока.

> [!warning] Затенение — источник багов
> Компилятор молчит по умолчанию. Включи `-Wshadow` (clang/gcc), чтобы он предупреждал.

> [!note] Из Python
> В Python блок `if`/`for` **не** создаёт область видимости — переменная живёт до конца функции. В C++ создаёт любой `{ }`. См. [Из Python в C++](<./Из Python в C++.md>).

## Область видимости ≠ время жизни

Курс их не разделяет, а это разные вещи: *где имя доступно* и *сколько существует сама память*.

| Класс | Когда создаётся / уничтожается | Начальное значение |
|---|---|---|
| **автоматическая** (локальная) | вход/выход из блока, лежит на стеке | **мусор** |
| **статическая** (глобальная, `static`) | старт/конец программы | **нули** |

```cpp
void f() {
    int a;          // мусор при каждом вызове
    static int b;   // 0, создаётся один раз, живёт до конца программы
}
```

Ключевое слово `static` у локальной переменной **не меняет** её область видимости (она по-прежнему видна только внутри блока), но меняет время жизни — значение сохраняется между вызовами.

```cpp
void counter() {
    static int n = 0;   // инициализируется ровно один раз
    cout << ++n << " ";
}
// три вызова напечатают: 1 2 3
```

> [!note] Почему глобальные заполнены нулями, а локальные — нет
> Статическая память выделяется при загрузке программы, и ОС обязана отдать её обнулённой (иначе утекли бы чужие данные). Локальные лежат на стеке поверх остатков предыдущих вызовов — обнулять их каждый раз было бы дорого. Отсюда правило из [03 Переменные и константы](<./03 Переменные и константы.md>): инициализируй всегда сам.
