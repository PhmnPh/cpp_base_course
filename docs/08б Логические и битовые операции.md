# 08б. Логические, сравнения и битовые операции

← [C++ — оглавление](<./C++ — оглавление.md>) · продолжение [08 Операции и выражения](<./08 Операции и выражения.md>)

В уроке 9 таблица операций была картинкой, и логическая часть в текст не попала. Без неё не написать ни одного условия, поэтому разбираем здесь.

## Сравнения

| | |
|---|---|
| `a == b` | равно |
| `a != b` | не равно |
| `a < b` `a > b` `a <= b` `a >= b` | сравнения |

Результат — `bool`.

> [!danger] `=` вместо `==`
> ```cpp
> if (x = 5)   // присваивание! x станет 5, условие всегда истинно
> if (x == 5)  // сравнение
> ```
> Компилируется без ошибки. `-Wall` предупредит.

> [!danger] Цепочки не работают как в математике
> ```cpp
> if (1 < x < 10)     // всегда true!
> ```
> Вычисляется слева направо: `(1 < x)` даёт `true`/`false` → `1`/`0`, а `0 < 10` и `1 < 10` истинны всегда. Правильно: `if (1 < x && x < 10)`.
> В Python `1 < x < 10` работает как ожидается — это ровно тот случай, где привычка подводит ([Из Python в C++](<./Из Python в C++.md>)).

> [!warning] `==` для вещественных
> Не сравнивай `double` на равенство → см. [02 Данные в памяти компьютера](<./02 Данные в памяти компьютера.md>). Используй `fabs(a - b) < 1e-9`.

## Логические

| | | Пример |
|---|---|---|
| `!a` | НЕ | `!flag` |
| `a && b` | И | `x > 0 && x < 10` |
| `a \|\| b` | ИЛИ | `c == 'y' \|\| c == 'Y'` |

Любое число приводится к `bool`: **`0` → `false`, всё остальное → `true`** (в том числе отрицательные).

### Короткое замыкание

`&&` и `||` вычисляют правый операнд **только если нужно**:

- `a && b` — если `a` ложно, `b` не вычисляется вовсе
- `a || b` — если `a` истинно, `b` не вычисляется

Это не оптимизация, а гарантия стандарта, на которой строят защиту:

```cpp
if (b != 0 && a / b > 2)     // деления на 0 не будет
if (i < n && arr[i] == x)    // выхода за границу не будет
```

> [!warning] Побочные эффекты в правом операнде
> `if (f() || g())` — `g()` может не вызваться никогда. Не прячь туда важные действия.

## Битовые операции

Работают с отдельными битами целых чисел. Не путать с логическими: `&` ≠ `&&`.

| | | Пример (на байте) |
|---|---|---|
| `~a` | инверсия | `~0b0000'1111` = `1111'0000` |
| `a & b` | И побитово | `1100 & 1010` = `1000` |
| `a \| b` | ИЛИ побитово | `1100 \| 1010` = `1110` |
| `a ^ b` | исключающее ИЛИ | `1100 ^ 1010` = `0110` |
| `a << n` | сдвиг влево | `1 << 3` = `8` |
| `a >> n` | сдвиг вправо | `20 >> 2` = `5` |

Сдвиг влево на `n` = умножение на `2ⁿ`, вправо = целочисленное деление на `2ⁿ`.

Практические приёмы:

```cpp
n % 2 == 1      ≡  n & 1        // проверка на нечётность
n / 2           ≡  n >> 1       // для неотрицательных
n * 8           ≡  n << 3
```

> [!note] Зачем это знать сейчас
> В курсовых задачах битовые операции не нужны — но `<<` и `>>` ты уже используешь с `cout`/`cin`. Это те же самые операторы, просто **перегруженные** для потоков. Отсюда и одна из причин ставить скобки:
> ```cpp
> cout << a & 1;      // ошибка: << приоритетнее &
> cout << (a & 1);    // правильно
> ```

## Приоритет: что важно запомнить

```
!  ~  (унарные)
*  /  %
+  -
<<  >>
<  <=  >  >=
==  !=
&
^
|
&&
||
?:
=  +=  ...
```

Ключевые следствия:
- арифметика **выше** сравнений: `a + b > c` ≡ `(a + b) > c` ✔
- сравнения **выше** `&&` и `||`: `x > 0 && y > 0` работает без скобок ✔
- `&&` **выше** `||`: `a || b && c` ≡ `a || (b && c)` — вот здесь скобки поставь явно
- битовые `& | ^` **ниже** сравнений — это исторический баг дизайна C: `a & 1 == 0` означает `a & (1 == 0)`. Всегда скобки.
